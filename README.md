# 📊 E-Commerce Sales Analytics & AI-Assisted Business Insights

An end-to-end **Data Analyst portfolio project** that transforms e-commerce sales data into interactive dashboards and business insights using **Excel, MySQL, Power BI, DAX, and Generative AI**.

## 🛠️ Tools & Technologies

| Tool              | Purpose                       |
| ----------------- | ----------------------------- |
| **Excel**         | Data cleaning and preparation |
| **MySQL**         | Database and SQL analysis     |
| **Power BI**      | Interactive dashboard         |
| **DAX**           | KPI and analytical measures   |
| **Generative AI** | AI-assisted business insights |

## 🔄 Project Workflow

**Raw Data → Excel → MySQL → Data Modeling → Power BI → DAX → Dashboard → AI Business Insights**

## 📊 Dashboard

The Power BI dashboard provides interactive analysis of:

* Sales performance
* Profitability
* Product and category performance
* Customer segments
* Geographic performance
* KPI metrics
* Interactive filtering

## 🤖 AI Business Insights

A dedicated AI Business Insights page was developed to interpret the dashboard results and translate the findings into concise business recommendations.

The AI analysis is used as a supporting layer based on the available dashboard results.

## 💡 Business Recommendations

1. Prioritize deeper analysis of high-performing categories, customer segments, and geographic markets.
2. Investigate Binders performance across sales, profitability, pricing, and customer distribution.
3. Analyze profitability by product, category, customer segment, and state to identify opportunities for improvement.
